# Project localization rules

- Any code, feature, UX, prompt, warning, error, or documentation change that adds or changes user-visible text must update the corresponding translations in all five supported languages: `en`, `es`, `fr`, `ro`, and `de`.
- Keep terminology natural and consistent for each language. Do not leave accidental English wording in non-English translations. Preserve technical names, commands, file names, and parameter names when they must remain exact.
- Use these key names consistently in user-facing prompts: English `ENTER`; Spanish `INTRO`; French `ENTRÉE`; Romanian `ENTER`; German `EINGABE` or `EINGABETASTE`.
- Before completing a change, inspect the affected translation tables together and verify that no supported language was omitted.
